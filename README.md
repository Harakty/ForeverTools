# ForeverTools

A focused personal Windows launcher and addon manager planned for World of Warcraft: Forever.

**Status: planning and API-access evaluation. No runnable launcher, addon catalogue or installer is available yet.**

[Project website](https://harakty.github.io/ForeverTools/) · [Product brief](docs/product-brief.md)

## Intended experience

- Launch the selected WoW Forever installation.
- Browse an on-demand catalogue by category, search, downloads and user ratings where the source provides them.
- Install or update only the addons the user chooses.
- Keep local backups of installed addon files and support rollback.

The catalogue is a reference shelf. There are no planned discovery notifications, personalized recommendation feeds, daily installation prompts or automatic installations of newly listed addons.

## Catalogue and distribution

CurseForge is a proposed catalogue and download provider, subject to approval of API access and this use case. Availability of ratings and Forever-specific download counts has not been verified. Downloads will respect author permission and the approved provider's conditions. The project will not rehost addon archives.

Metrics will identify their source and scope. Project-wide WoW downloads will not be presented as Forever-only downloads. Declared compatibility and locally tested compatibility will be distinguished. No persistent API-data cache is assumed without permission.

## Development

The first milestone is this public project description and specification for the API application. The runtime technology and implementation will be selected after the provider constraints are confirmed.

The project is intended for personal, non-commercial use, with no planned ads, subscriptions, donations or user tracking.
