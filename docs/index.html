Personal Windows project

ForeverTools

A focused launcher for WoW Forever, with an addon catalogue you consult when you need it.

Planning & API-access evaluation.
No runnable launcher, live catalogue or installer is available yet.

Planned features

  • Launch your selected WoW Forever installation.
  • Search addons by category and browse downloads or user ratings where available.
  • Install and update only the addons you choose.
  • Keep backups of changed addon files and restore a previous version.

The catalogue is a reference shelf: no discovery notifications, personalized feeds or automatic installations of newly listed addons.

Real metrics, clear compatibility

Each popularity metric will identify its source and scope. Whole-project WoW downloads will be distinguished from Forever-specific downloads. Declared support and locally tested compatibility will be shown separately.

API access comes first

CurseForge is a proposed source, subject to approval. Ratings availability, Forever filtering, quotas, costs and permitted data handling still need confirmation. Downloads will respect author permission; addon archives will not be rehosted.

This is a personal, non-commercial project with no planned advertising, subscriptions, donations or user tracking.
